# FocusFlow

FocusFlow — адаптивное приложение для планирования задач, фокус-сессий и личной продуктивности. Интерфейс полностью на русском языке; демо-задачи загружаются при первом запуске, а изменения сохраняются в браузере.

## Требования

- Node.js 20.19+ или 22.12+
- npm

## Установка и запуск

```bash
npm install
npm run dev
```

Откройте адрес, напечатанный Vite в терминале (обычно `http://localhost:5173`).

## Проверка и production-сборка

```bash
npm run build
npm run preview
```

## Возможности

- Создание, изменение, удаление и завершение задач с приоритетами.
- Фильтрация задач и сохранение списка в `localStorage`.
- Pomodoro-таймер с запуском, паузой и сбросом.
- Прогресс за день и недельная визуализация активности.
- Форма подписки с подтверждением и адаптивная навигация.

Внешние сервисы и ключи API не требуются.
